# Sistemas Operativos

Repositorio de prácticas, programas y simuladores para la materia de **Sistemas Operativos**.

🔗 **Simulador en Vivo (GitHub Pages):** [https://atos333.github.io/Sistemas-Operativos/](https://atos333.github.io/Sistemas-Operativos/)

---

## 📌 Contenido del Repositorio

### 🌐 Simulador de Monitor (`index.html`)
- Interfaz interactiva desplegada en GitHub Pages para la visualización del mecanismo de sincronización por **Monitores**, variables de condición (`wait()` y `signal()`), cola de entrada y exclusión mutua.

### 💻 Programa 1: Procesamiento por Lotes
- Implementación de la simulación de procesamiento por lotes con operaciones matemáticas y control de tiempos.
- Incluye script en Python (`programa 1.py`) y ejecutable (`programa 1.exe`).

### 💻 Programa 2: Multiprogramación y Cola de Procesos
- Algoritmo de multiprogramación con gestión de estados (Nuevo, Listo, Ejecución, Bloqueado, Terminado).
- Visualización con formato tipo pizarra y métricas.
- Incluye reporte técnico completo en PDF, HTML y Markdown (`Reporte_Programa_2.pdf`, `reporte_programa_2.md`).

### 💻 Programa 3: Métricas de Tiempo y Bloqueados
- Algoritmo extendido con cálculo de métricas de rendimiento por proceso:
  - Tiempo de Llegada
  - Tiempo de Finalización
  - Tiempo de Retorno
  - Tiempo de Respuesta
  - Tiempo de Espera
  - Tiempo de Servicio
- Manejo de cola de bloqueados y transiciones en tiempo real.
